# El secreto del Arocena

Propuesta académica de escape room educativo para el Museo Arocena, desarrollada por un equipo del Tec de Monterrey, Campus Laguna.

La [landing page](landing/) presenta la experiencia y un acertijo interactivo. El navegador consulta las tres fichas en Supabase. Puedes comprobar la respuesta, pedir ayuda y volver a intentarlo.
